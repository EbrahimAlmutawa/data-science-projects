# Data Science Projects 📊

A collection of small, hands-on data science projects I'm building while learning — part of my BSc in Data Science & Business Analytics at BIBF / University of London.

The goal isn't polished, production-ready work. It's **learning by doing**: picking a dataset, asking questions, and practicing the tools (Python, pandas, SQL, visualization, and eventually Power BI) on real data.

---

## 📁 Structure

Each project lives in its own folder, named for the project:

```
data-science-projects/
├── project-01-name/
│
├── project-02-name/
└── ...
│
└── README.md               ← you are here
```

---

## 🛠️ Tools I'm Practicing

- **Python** — pandas, numpy, matplotlib/seaborn
- **SQL** — querying and cleaning data
- **Jupyter Notebooks** — for exploration and write-ups
- **Power BI** — dashboards (coming soon)

---

## 🎯 Why This Repo Exists

I'm early in my data science journey, and I'd rather learn in public with small, honest projects than wait until I feel "ready." Each project here is a checkpoint — not perfect, but a real step forward. Feedback and suggestions are always welcome.
