# Data Science Projects 📊

A collection of small, hands-on data science projects I'm building while learning — part of my BSc in Data Science & Business Analytics at BIBF / University of London.

The goal isn't polished, production-ready work. It's **learning by doing**: picking a dataset, asking questions, and practicing the tools (Python, pandas, SQL, visualization, and eventually Power BI) on real data.

---

## 📁 Structure

Each project lives in its own folder, named for the project:

```
data-science-projects/
├── project-01-name/
│   ├── README.md          ← what the project does, what I learned
│   ├── data/               ← raw or sample data (or a link if too large)
│   ├── notebook.ipynb      ← the actual analysis
│   └── images/              ← charts/screenshots used in the README
├── project-02-name/
│   └── ...
└── README.md               ← you are here
```

Every project folder has its own README explaining the question I was exploring, the approach, and the results — so each one can be read on its own.
